# Мій світ

Клікабельна сцена: тицяєш на точку й заходиш у місце з фото та текстом.

## Що змінювати
Усе в файлі `places.js`: назви місць, тексти, координати точок і список фото.
Свої фото клади в папку `photos/`. Назви латиницею, без пробілів. Краще стиснути до 1–2 МБ.
Фон — це `photos/town.jpg`, його можна замінити на іншу картинку.
Координати точок у відсотках. Щоб їх знайти, відкрий сайт із `#edit` в кінці адреси й клікай по карті.

## Як викласти на GitHub Pages
1. Створи репозиторій на github.com (Public).
2. Завантаж усі файли: Add file, Upload files.
3. Settings, Pages, Source: Deploy from a branch, гілка main, папка / (root), Save.
4. Через хвилину-дві сайт буде на `https://ТВІЙ_НІК.github.io/НАЗВА_РЕПО/`. Цим посиланням можна ділитися.

Увага: у публічному репозиторії фото бачитимуть усі.
